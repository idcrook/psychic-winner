# Car Cupholder magsafe charger mount

Have been using a variant of [Bicycle and Car iPhone 6 Plus Mount family by dpc - Thingiverse](https://www.thingiverse.com/thing:1456819) for over a decade, but recently got an urge to try MagSafe charger / mount in the car.

Had an Apple MagSafe charger with USB-C laying around. Found a [desktop design][magsafe_desk_dock] to leverage into a car cup-holder one.

One key difference in this model vs. the past-decade ones is that it is monolithic- there is no interface/splitting of the cup-holder part with the top magsafe holder part.

The design still retains the opening for placing heavy objects (for example, coins) into the cupholder base to anchor it down.
